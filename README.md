# Tesi: Rilevamento Anomalie Termiche

Questo repository contiene il codice e i materiali per la tesi di laurea sul rilevamento di anomalie in immagini termiche.

## Configurazione Ambiente di Sviluppo

Per eseguire questo progetto, è necessario attivare l'ambiente virtuale Python dedicato.

### Prerequisiti
* Python 3.x
* `venv` (modulo Python)
* Git

### Attivazione Ambiente (Linux/Debian)

1.  Aprire un terminale nella cartella principale del progetto (`tesi_termica`).
2.  Eseguire il seguente comando per attivare l'ambiente virtuale:

```bash
source .venv/bin/activate
